# Sniper Duel

A 2D sniper-duel game in Phaser 3. Hunt enemy snipers hiding in the windows of a city skyline — scope in to shoot, but scoping exposes you to their fire. Duck behind cover before they lock on.

**Play:** https://greennovastar.github.io/sniper-duel/

## Controls

- **Hold right-click** — scope in (drops your cover, exposes you)
- **Left-click** — fire (bolt-action: ~2s between shots)
- **Mouse to screen edge** — pan across the city
- Duck (release right-click) when you see the yellow glint — they're about to fire

No build step: plain HTML + JS, Phaser loaded from CDN. Open `index.html` in a browser to play locally.
